# Amazon Clone Project

Create a faithful frontend clone of the Amazon homepage from the attached screenshot. Include the Amazon header with logo, location selector, search bar with category dropdown, account/cart navigation, sub-navigation bar, delivery address popup banner, the Valentine's Day hero banner with slider controls, and the featured card grid (Shop by Category, Refresh your space, Electronics, sign-in card, and global shipping promo). Keep tabs and links visual placeholders for now so we can activate each feature step by step.
